\# ScamSathi AI



An AI-powered scam message detection project focused on Tamil, Tanglish, and English messages.



\## Objectives

\- Detect potentially suspicious messages.

\- Explain suspicious words and warning signs.

\- Provide a risk score and safety recommendations.

\- Evaluate the model using test data.



\## Technology Stack

\- Python

\- Machine Learning

\- Scikit-learn

\- SQLite

\- FastAPI (planned)

\- React (planned)



\## Project Status

Initial setup in progress.



\## Disclaimer

Predictions are estimates, not proof that a message is fraudulent.

Always verify suspicious messages through official sources.
